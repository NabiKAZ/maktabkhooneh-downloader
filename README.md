# 🚀 Maktabkhooneh Downloader PLUS (2026 Edition)

<div dir="rtl">

یک ابزار قدرتمند، فوق‌سریع و هوشمند مبتنی بر **Node.js** برای دانلود کامل، دسته‌بندی‌شده و خودکار دوره‌ها، ویدیوها، زیرنویس‌ها، ضمائم و آزمون‌های سایت **مکتب‌خونه** با پشتیبانی از هر دو ساختار **قدیمی (Legacy)** و **جدید (Nuxt 3 LMS)**.

</div>

---

## ✨ ویژگی‌های کلیدی (Key Features)

<div dir="rtl">

- 🧠 **تشخیص هوشمند و واحد به واحد ساختار (Unit-by-Unit Hybrid Detection):**
  تشخیص خودکار و مستقل ساختار هر درس؛ بدون نیاز به تعیین دستی اینکه دوره قدیمی است یا LMS جدید.
- 🎬 **پشتیبانی از بالاترین کیفیت ویدیو (1080p Full HD & 720p HQ):**
  انتخاب خودکار بهترین و بالاترین کیفیت استریم موجود برای هر درس.
- 📝 **استخراج آزمون‌ها و مقالات به فرمت Markdown (`.md`):**
  تبدیل خودکار دروس متنی، کوئیزها و تمرین‌ها به فایل‌های Markdown مرتب همراه با گزینه‌های تعاملی (`- [ ]`).
- 💬 **دانلود خودکار زیرنویس‌ها (`.vtt`):**
  دریافت مستقیم زیرنویس فارسی دروس در صورت وجود در کنار فایل ویدیویی.
- 📎 **دانلود ضمائم و فایل‌های تمرینی:**
  دانلود تمام فایل‌های پیوست شامل اسلایدها (PDF/PPTX)، کدهای نمونه و فایل‌های فشرده (ZIP/RAR).
- 🔄 **پشتیبانی کامل از سرگیری دانلود (Resume & HTTP Range):**
  استفاده از فایل‌های موقت `.part` و ارسال درخواست‌های Range؛ در صورت قطعی اینترنت، دانلود از همان بایت قطع‌شده ادامه می‌یابد.
- 🛡️ **پایداری در برابر حجم‌های نامشخص (Unknown Size & Chunked Streaming):**
  عدم توقف یا صفر در نظر گرفتن فایل در صورت عدم ارسال هدر Content-Length از طرف سرور.
- 🔐 **روش‌های منعطف احراز هویت:**
  - ورود خودکار با نام‌کاربری و رمز عبور (`user.txt` یا فلگ‌های خط فرمان)
  - ذخیره و استفاده مجدد از نشست‌ها در `session.json` چندکاربره
  - پشتیبانی از فایل خروجی کوکی مرورگر (`cookies.txt` با فرمت استاندارد Netscape)
  - پشتیبانی از متغیرهای محیطی `MK_COOKIE` و `MK_COOKIE_FILE`
- 📊 **حالت بازرسی سرفصل‌ها بدون دانلود (`--info` / `--table`):**
  مشاهده جدول کامل دروس، نوع محتوا، وضعیت دسترسی و تخمین حجم کل دوره در قالب جدول کنسول.
- 🧪 **حالت نمونه تستی (`--sample-bytes`):**
  امکان دانلود فقط N بایت اول هر فایل برای تست و اطمینان از سلامت لینک‌ها و سرعت اینترنت.
- ⚡ **بدون وابستگی سنگین (Zero External Dependencies):**
  اجرای سریع و سبک روی Node.js 18+ با استفاده از ماژول‌های استاندارد و Fetch بومی.

</div>

## 📥 نحوه راه‌اندازی و استفاده (Usage Guide)

### ۱. کلون یا دانلود مخزن
```bash
git clone https://github.com/NabiKAZ/maktabkhooneh-downloader.git
cd maktabkhooneh-downloader
```

---

### ۲. وارد کردن آدرس دوره‌ها

<div dir="rtl">

آدرس دوره‌های مورد نظر خود را در فایل `link.txt` قرار دهید (هر خط یک آدرس):

</div>

```text
https://maktabkhooneh.org/course/آموزش-پیکربندی-سرور-hpe-mk3160/
https://maktabkhooneh.org/course/آموزش-شبکه-مبتدی-استفاده-cisco-packet-tracer-mk9970/
```

> **نکته:** همچنین می‌توانید آدرس دوره را مستقیماً به عنوان آرگومان به دستور بدهید.

---

### ۳. تنظیمات ورود به حساب کاربری (اختیاری برای دوره‌های خریداری‌شده/اشتراکی)

#### روش الف: فایل `user.txt`
<div dir="rtl">

یک فایل به نام `user.txt` در کنار اسکریپت بسازید؛ در خط اول ایمیل و در خط دوم رمز عبور را بنویسید:

</div>

```text
your_email@example.com
your_password
```

#### روش ب: استفاده از فایل کوکی مرورگر (`cookies.txt`)
<div dir="rtl">

با استفاده از افزونه‌های مرورگر (مانند *Get cookies.txt LOCALLY*) کوکی‌های سایت مکتب‌خونه را در فایلی به نام `cookies.txt` خروجی بگیرید و در کنار برنامه قرار دهید یا با سوئیچ `--cookie-file` آن را مشخص کنید.

</div>

## 💻 دستورات اجرا (Commands)

### اجرای عادی (دانلود تمام دوره‌ها)
```bash
node download.mjs
```

### دانلود یک دوره مشخص از طریق خط فرمان
```bash
node download.mjs "https://maktabkhooneh.org/course/ceh-v13-mk15880/"
```

### مشاهده جدول سرفصل‌ها و تخمین حجم بدون دانلود (`--info`)
```bash
node download.mjs --info
```

### ورود مستقیم با پارامترهای خط فرمان
```bash
node download.mjs --user you@example.com --pass "your_password"
```

### استفاده از فایل کوکی
```bash
node download.mjs --cookie-file my_cookies.txt
```

### تست دانلود با دریافت بخش ابتدایی فایل‌ها (مثلاً ۱ مگابایت)
```bash
node download.mjs --sample-bytes=1048576 --verbose
```

## ⚙️ جدول گزینه‌ها و سوئیچ‌های خط فرمان (CLI Options)

| گزینه (Option) | مخفف | توضیحات |
| :--- | :---: | :--- |
| `--help` | `-h` | نمایش راهنمای کامل برنامه |
| `--info`, `--table` | | فقط نمایش فهرست دروس، وضعیت و حجم بدون دانلود |
| `--user`, `--email` | | ایمیل حساب کاربری مکتب‌خونه |
| `--pass`, `--password`| | رمز عبور حساب کاربری |
| `--cookie-file` | | مسیر فایل کوکی Netscape (`cookies.txt`) |
| `--session-file` | | مسیر ذخیره سشن احراز هویت (پیش‌فرض: `session.json`) |
| `--log-file` | | مسیر ذخیره فایل لاگ (پیش‌فرض: `downloader.log`) |
| `--sample-bytes` | | دانلود تستی N بایت اول از هر ویدیو |
| `--verbose` | `-v` | نمایش لاگ‌های دقیق دیباگ و مراحل اتصال |
| `--force-login` | | اجبار به لاگین مجدد و نادیده گرفتن سشن ذخیره‌شده |
